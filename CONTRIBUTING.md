# Contributing

Thank you for helping improve GLB Export Optimizer.

## Bug reports
Use the GitHub Bug Report issue template. Include:
- Add-on version
- Blender version
- Operating system
- Exact reproduction steps
- Relevant error output

## Feature requests
Use the Feature Request template and explain the workflow problem the feature would solve.

## Pull requests
Please describe the change and test it in Blender where possible. Avoid including proprietary assets or confidential client files.

By submitting contributions, you agree that your contributions are provided under the project's GPL-3.0-or-later license.
